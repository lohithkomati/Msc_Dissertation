# Vagus AI

## MSc Dissertation Project

Vagus AI is an MSc dissertation project developed as part of the MSc Data Science programme at the University of Leicester.

## Project Overview

This project focuses on the development of an AI-based application using a full-stack architecture.

The project consists of a backend and frontend application:

- **Backend** – Handles the server-side application and API functionality.
- **Frontend** – Provides the user interface for interacting with the application.
- **Main application** – Provides the project entry point and application integration.
